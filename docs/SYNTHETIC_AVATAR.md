# Synthetic geometric avatar

The `synthetic-avatar` scene is an original fixture made in the shared Three.js renderer from simple boxes and spheres. It uses no photograph, face scan, biometric measurement, downloaded model, likeness of a real person or external texture. Its implementation is covered by this repository's MIT licence; Three.js retains its own MIT notice.

The visible label “Synthetic avatar - no real person” is fixed outside the animated root so it remains front-facing. The representation uses the existing bounded absolute-time animation, resource disposal, project revision and render-plan binding. Changing the scene, accent or labels requires saving a new revision and obtaining a new render approval.

This delivers a fictional demonstrator, not personal avatar creation, motion capture, VRM import, lip synchronisation or consent verification. A real person's avatar and any externally supplied model require separate rights and technical validation. Source lineage and uncertainty controls still apply to the surrounding content; this fixture does not certify that content.
