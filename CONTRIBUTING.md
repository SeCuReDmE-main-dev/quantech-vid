# Contributing

Thank you for helping QuaNTecH-ViD serve podcast creators.

## Development flow

1. Open or select one bounded issue.
2. Describe the user, expected result, and proof.
3. Keep provider-specific behavior behind an adapter.
4. Add or update tests.
5. Run Python tests and the Chrome contract suite.
6. Submit a focused pull request with screenshots or trace receipts when relevant.

## Quality expectations

- Preserve source fidelity and provenance.
- Keep costly or public mutations behind approval.
- Treat voice and avatar identity as consented assets.
- Return typed errors and compact tool results.
- Label experimental integrations clearly.
- Add an eval whenever a traced failure produces a fix.
